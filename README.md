# Rocky

Live assistant for macOS and Windows: the voice of chat, with notes and ideas during a stream.

Rocky is in planning. It is proposed as a Kotlin Multiplatform and Compose Multiplatform project, with local data and AI chosen by the user. There is no executable application yet.

Read the [implementation plan](docs/PLANO.md) for the product, privacy, integrations, architecture, monorepo, phases, and release criteria. The plan is currently available in Portuguese.
