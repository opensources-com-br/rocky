LOCAL-FIRST BY DESIGN

Your setup remains yours.

Rocky does not require a Rocky account or backend. Notes and provider settings stay on the user's computer so the configuration remains available after reopening.

When you select a cloud AI provider, the chat messages used as context are sent to that provider. Ollama can run the suggestion flow locally.

Data handling and deletion · Saved AI keys use system credential storage. Voice is optional.
