# Homologação do primeiro uso e configurações

Execute no macOS e Windows antes de publicar uma versão.

- [ ] A primeira abertura exibe o guia de configuração.
- [ ] Plataforma e IA são obrigatórias para concluir.
- [ ] É possível concluir sem configurar voz.
- [ ] O guia não reaparece depois de reiniciar.
- [ ] A busca filtra e abre a seção correta.
- [ ] Os valores permanecem ao alternar entre abas.
- [ ] Credenciais podem ser salvas, editadas e removidas.
- [ ] Trocar provedor não reaproveita a chave anterior.
- [ ] Redefinir configurações preserva notas e ideias.
- [ ] Navegação, foco e leitura funcionam pelo teclado.
