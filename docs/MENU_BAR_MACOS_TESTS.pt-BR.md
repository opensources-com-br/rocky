# Homologação da menu bar no macOS

Execute com o DMG publicado nos temas claro e escuro.

- [ ] Rocky inicia sem ícone no Dock.
- [ ] O ícone adapta-se aos temas claro e escuro.
- [ ] `Rocky`, `Settings` e `Quit` funcionam.
- [ ] Rocky e Settings permanecem independentes.
- [ ] Fechar as janelas mantém a menu bar ativa.
- [ ] Janelas minimizadas são restauradas pelo menu.
- [ ] Cliques repetidos não duplicam as janelas.
- [ ] O ícone permanece correto após trocar resolução ou monitor.
