# Documentação do Rocky

Os guias abaixo descrevem o aplicativo no código atual. Instaladores já publicados podem corresponder a commits anteriores; confira a versão e o commit em Configurações → Dados.

- Configuração: [Twitch](TWITCH.pt-BR.md), [Kick](KICK.pt-BR.md), [YouTube](YOUTUBE.pt-BR.md), [Facebook](FACEBOOK.pt-BR.md), [IA](AI.pt-BR.md) e [voz](VOICE.pt-BR.md).
- Durante a live: [perguntas, registros e manutenção](MVP_CHAT_WORKSPACE.pt-BR.md).
- Dados: [privacidade, backup e credenciais](PRIVACY.md).
- Distribuição: [preparação do candidato](RELEASE_PREPARATION.md), [validação desktop](VALIDATION.pt-BR.md), [roteiro atual](TEST_TODAY.pt-BR.md) e [teste com streamers](STREAMER_TEST.pt-BR.md).
- Implementação: READMEs dos módulos e [dependências nativas](DEPENDENCIES.md).
- Web: conteúdo em apps/web/content/, com [registro da auditoria](../apps/web/CONTENT_AUDIT.md). A web documenta o desktop; não conecta plataformas nem recebe relatos pelo Showcase.

Os guias de configuração também têm versões em inglês neste diretório.
