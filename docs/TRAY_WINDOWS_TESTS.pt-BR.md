# Homologação do tray no Windows

Execute em Windows 11 com o MSI publicado e registre versão, escala e monitores usados.

- [ ] Rocky inicia oculto na área de notificação.
- [ ] O ícone aparece na seta de ícones ocultos.
- [ ] O ícone permanece legível nos temas claro e escuro.
- [ ] Clique simples no ícone abre o Rocky.
- [ ] `Rocky` abre e restaura a janela principal.
- [ ] `Settings` abre uma janela independente.
- [ ] `Quit` encerra completamente o processo.
- [ ] Fechar Rocky mantém o processo no tray.
- [ ] Fechar Settings mantém o processo no tray.
- [ ] Minimizar e reabrir pelo tray restaura a janela.
- [ ] Cliques repetidos em Rocky não duplicam a janela.
- [ ] Cliques repetidos em Settings não duplicam a janela.
- [ ] Reiniciar o Explorer recupera o ícone.
- [ ] Validar escalas de 100%, 125%, 150% e 200%.
- [ ] Validar com um e múltiplos monitores.
- [ ] Validar a barra de tarefas em posições e monitores diferentes.
