# Homologação de janelas e interface

Execute no macOS e Windows com escalas, idiomas e monitores diferentes.

- [ ] Mover e redimensionar a janela principal.
- [ ] Respeitar o tamanho mínimo.
- [ ] Persistir posição e tamanho depois de reiniciar.
- [ ] Recuperar a janela depois de remover um monitor.
- [ ] Alternar sempre no topo.
- [ ] Alternar compacto/expandido preservando o tamanho anterior.
- [ ] O atalho global mostra e oculta a janela.
- [ ] Settings não altera o tamanho da janela principal.
- [ ] Navegar completamente pelo teclado.
- [ ] Manter uma ordem de foco previsível.
- [ ] Leitores de tela anunciam campos e botões.
- [ ] Manter contraste nos temas claro e escuro.
- [ ] Não cortar textos com escala ou fonte ampliada.
- [ ] Exibir PT-BR e inglês em todas as telas.
- [ ] Persistir o idioma depois de reiniciar.
